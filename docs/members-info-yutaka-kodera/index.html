業務内容
小売電気事業
売上
売上16.4億円（2025年6月末時点）
社業における得意分野・PRポイント
・日本全国で電力小売事業を展開し、電気料金の削減を実現。
・再生可能エネルギー（太陽光・風力・水力など）の電源開発を推進。
・NON-FIT電源やFIT終了後電源の買取を積極的に実施。
・公益社団法人日本青年会議所の賛助企業として、地域社会や青年経済人との連携を強化。
・不動産事業の経営を兼務し、エネルギーと不動産の両面から地域活性化に貢献。
・行政書士事務所の代表として、外国人のビザ申請や会社設立手続きなど幅広い法務支援を展開。
